## Q1. Reward Model과 PPO KL Penalty

RLHF는 세 단계로 구성됩니다: SFT → Reward Model 학습 → RL(PPO) 최적화.

**두 가지를 설명하세요:**

1. **Reward Model의 학습 손실함수** — 인간의 선호 데이터 $(x, y_w, y_l)$이 주어졌을 때, Reward Model $r_\phi$를 어떻게 학습하는지 수식으로 설명하세요.

$$\mathcal{L}_{RM} = -\mathbb{E}_{(x,\, y_w,\, y_l) \sim \mathcal{D}}\!\left[\log \sigma\!\left(r_\phi(x, y_w) - r_\phi(x, y_l)\right)\right]$$

2. **PPO의 KL Penalty** — RLHF에서 PPO로 LM을 최적화할 때, Reward에 KL 패널티를 추가하는 이유를 설명하세요.

$$r(x, y) = r_\phi(x, y) - \beta \cdot \mathbb{KL}\!\left[\pi_\theta(y \mid x) \;\|\; \pi_{\text{ref}}(y \mid x)\right]$$

### Answer 1.

1. 사람이 직접 "이 응답이 저 응답보다 낫다"는 선호 데이터를 이용해서 응답의 품질을 점수로 매기는 모델 $r_\phi(x, y)$를 학습한다.

즉, 손실함수는 $y_w$의 점수가 $y_l$의 점수보다 높을 확률을 최대화 하는 것으로 볼 수 있다.

2. 만약 KL penalty가 없이 reward만 최대화하게 된다면, reward model의 취약점을 파고드는 응답(e.g 무의미한 반복, 반드시 동의)을 생성하게 된다. 따라서 기존 SFT 모델에서 크게 벗어나지는 않되, reward를 최대화하도록 하기 위해서 KL penalty가 필요하다.

- $\beta$가 크면, SFT 모델에서 크게 벗어나지 않게 된다.(=안정적이지만 모델 개선이 느림)
- $\beta$가 작으면, reward를 최대화하는 것에 더 집중하게 된다.(=개선이 빠르지만 reward hacking의 위험이 존재)

## Q2. DPO의 이점

**DPO(Direct Preference Optimization)**는 Reward Model 없이 직접 선호 데이터로 LM을 학습합니다.

**DPO가 RLHF-PPO 대비 갖는 이점을 설명하세요:**


$$\mathcal{L}_{\text{DPO}}(\pi_\theta;\pi_{\text{ref}}) = -\mathbb{E}_{(x,y_w,y_l)}\!\left[\log \sigma\!\left(\beta \log \frac{\pi_\theta(y_w \mid x)}{\pi_{\text{ref}}(y_w \mid x)} - \beta \log \frac{\pi_\theta(y_l \mid x)}{\pi_{\text{ref}}(y_l \mid x)}\right)\right]$$

### Answer 2.

PPO는 Critic 함수를 학습하는 Actor-Critic 구조라 모델이 사실상 2개가 필요하게 된다. 그러나 DPO는 별도로 Reward model을 두지 않는다.

실제로 DPO는 수학적으로 PPO와 동일하다. 따라서 SFT 모델($\pi_\text{ref}$)과 학습 대상인 모델($\pi_\theta$)만으로 선호를 직접 학습할 수 있다.

즉, DPO는 PPO에 비해 reward model이 필요 없으며, RL 루프가 필요 없고, 안정적으로 학습된다는 장점이 있지만, 표현력이 상대적으로 떨어질 수 있다는 것은 단점이다.

## Q3. GRPO vs PPO

최근 DeepSeek-R1 등에서 사용되어 주목받은 **GRPO(Group Relative Policy Optimization)** 는 PPO와 어떻게 다른가요?

특히 PPO가 필요로 하는 것 중 GRPO가 제거한 요소가 무엇인지, 그리고 **"Group"이라는 단어가 어디서 오는지** 설명해보세요.

### Answer 3.

GPRO에서는 PPO와는 다르게 Critic model(Value function)을 제거했다. PPO에서는 Advantage를 계산하기 위해서 별도의 Critic network를 사용했지만, 이 Critic network는 Policy network만큼 큰 모델이므로 메모리/연산 비용이 거의 2배가 된다는 단점이 있다.

GRPO는 프롬프트 1개에 대해서 여러 개($G$)의 응답을 생성하게 된다. 이때 각 응답에 대한 reward $\{r_1, r_2, ..., r_G\}$를 구한 뒤, 그룹의 평균/표준편차로 advantage를 정규화한다. 즉, "이 그룹 내에서 내 응답이 평균보다 얼마나 좋은가"를 baseline으로 쓴다. 

> **DPO와 GRPO의 차이** \
> DPO는 미리 수집된 선호 데이터를 통해서 학습이 진행되는 Offline 학습이고, \
> GRPO는 학습 중에 모델이 직접 답변을 생성하고, 답변에 대한 reward를 통해 모델을 학습하는 Online 학습이다.
