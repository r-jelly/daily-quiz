## Q1. LoRA의 저랭크 분해 원리와 파라미터 절감

LoRA(Low-Rank Adaptation)가 전체 파인튜닝처럼 모든 가중치를 업데이트하지 않고도 비슷한 성능을 내는 원리를 설명하세요. 무엇을 동결하고 무엇을 학습하는지, 가중치 업데이트 $\Delta W$를 어떻게 저랭크로 분해하는지, 그리고 그렇게 해도 성능이 유지되는 이유를 본인의 말로 설명해보세요.

### Answer 1.

Low-Rank Adaptation은 Pre-trained Weight은 동결하고, 그 위에 더해지는 Weight Update를 두 저랭크 행렬의 곱 $\Delta W = BA$로 근사한다.($B\in\mathbb{R}^{d\times r}$, $A\in\mathbb{R}^{r\times k}$, $r\ll\min(d,k)$)

이렇게 저랭크 행렬로 가중치 업데이트를 분해한다면 학습하는 파라미터가 $dk$에서 $(d+k)r$로 감소하게 된다. Pre-training이 이미 충분한 지식을 학습했으므로, Task adaptation에 실제로 필요한 변화는 훨씬 낮은 rank의 부분집합 안에 있다고 볼 수 있다. 즉, downstream task 적응에 필요한 가중치 변화의 intrinsic rank가 낮다는 것이다. 따라서 위와 같이 저랭크 행렬곱으로 가중치를 업데이트 해도 성능이 유지된다.

> **한 단계 더:** 대표 논문 LoRA (Hu et al., 2021), intrinsic dimension 관찰(Aghajanyan et al., 2020). 어느 레이어($W_q, W_v$)에 붙이는지가 $r$보다 중요할 수 있다는 실험, AdaLoRA(rank 동적 배분)까지 언급하면 좋다.

## Q2. 스케일링 계수와 초기화의 역할

LoRA 학습에서 forward pass는 $h = Wx + \frac{\alpha}{r}BAx$로 구성됩니다. 즉, $\Delta = BA$에 스케일링 계수 $\alpha / r$이 들어갑니다. 또한, 각 저랭크 행렬 $A, B$에 대해서 $A$는 random, $B=0$으로 초기화를 합니다.

위의 학습 과정에서 스케일링 계수 $\frac{\alpha}{r}$과 $B=0$ 초기화 두 가지가 어떤 역할을 하는지 설명해 주세요. 특히 $r$ 값을 바꿀 때 $\alpha$를 고정해두면 어떤 문제가 생기는지도 함께 생각해 보세요.

## Answer 2.

1. $BA$는 $r$개의 행렬 $b_ia_i$의 합이므로, $r$이 커진다면 합쳐지는 항의 개수가 늘어나 더 많은 세밀한 정보를 담을 수 있지만 $BA$ 자체의 스케일도 커지는 경향이 있다. 이 상태에서 스케일링 $\alpha/r$를 해주지 않으면, $r$을 바꿀때마다 최적의 learning rate이 달라져 매번 재조정해야 하는 문제가 생긴다. 해당 스케일링은 $BA$ 스케일이 커지는 효과를 정확히 상쇄해 $r$이 달라져도 $\Delta W$의 전체적 크기가 거의 일정하게 유지되도록 한다. $r$이 이러한 효과를 내는 변수이므로 $\alpha$를 고정해두고 $r$만 바꿔도 큰 문제가 없게 된다. 정리하면 $\alpha/r$의 효과는 "$r$ 선택과 learning rate 튜닝을 분리"시켜주는 것이 된다.

2. $B=0$ 초기화는 초기 시점에 $\Delta W = BA = 0$이 되어 pre-trained 모델의 출력을 그대로 보존하기 위함이다. 즉, 학습 시작 전부터 무작위 값이 base model에 섞이는 것을 방지하여 학습 안정성을 유지하는 역할을 한다. 만약, $B=0, A=0$이 된다면 $B$로 흐르는 gradient도 0이 되어 학습이 전혀 이루어지지 않고, $A=0$이라면 $B=0$보다 학습 불안정성이 떨어진다고 한다.

## Q3. base model 공유 + task별 adapter 교체의 이점

학습이 끝난 LoRA는 추론 시점에 원래 가중치에 병합(merge)할 수 있고, 그 덕분에 추가 latency가 거의 없다고 합니다. 이것이 수학적으로 왜 성립하는지, adapter tuning과 비교해 설명해보세요.

또한 여러 태스크를 다룰 때 base model을 그대로 두고 LoRA adapter만 갈아 끼우는 방식의 이점은 무엇인지 설명해보세요.

### Answer 3.

1. 기존 pre-trained model의 파라미터 $W$와 low-rank parameter $BA$는 행렬 차원이 같을 뿐 아니라, 선형성을 가지고 있다. 즉, $W'x = (W+BA)x = Wx + BAx$이므로 학습이 끝난 뒤 $B$와 $A$를 미리 곱해서 $W$에 더해놓으면, 추론 시점에는 별도의 연산없이 일반 가중치 행렬 $W'$ 하나만을 곱하면 된다. 즉, LoRA를 병합하는 것은 근사가 아니라, 수학적으로 완전히 동일한 결과를 내면서 추론 시 추가 latency를 0으로 만든다. 반면 adapter tuning은 모델의 layer 사이에 모듈을 삽입해서 학습하는 방식이므로 추론 경로가 길어져 latency가 생긴다.

2. 각각의 LoRA adapter는 $(d+k)r$개의 파라미터만 가지므로, downstream task에 full fine-tuned 모델의 $d\times k$ 파라미터를 저장하는 것 보다 훨씬 저장 비용이 적다. 즉, base model $W$는 고정된 채로 task 별로 작은 LoRA adapter만 갈아끼우면서 저장&메모리 효율성과 모듈성을 확보할 수 있다. 

> **한 단계 더:** QLoRA(base를 4-bit NF4로 양자화 + adapter만 학습)로 메모리를 크게 줄이는 확장을 언급할 수 있고, 하나의 base에 여러 adapter를 얹어 요청별로 스위칭하는 멀티-LoRA 서빙(S-LoRA), adapter 합성/가중 병합을 언급하면 좋다.

## 오늘의 수식 카드

**LoRA 저랭크 분해**

$$W' = W + \Delta W = W + \frac{\alpha}{r} BA, \quad B \in \mathbb{R}^{d \times r},\; A \in \mathbb{R}^{r \times k},\; r \ll \min(d, k)$$

$$W'x = Wx + \frac{\alpha}{r}BAx \quad(\text{선형성} \Rightarrow \text{merge 시 latency } 0)$$

| 기호 | 의미 |
|------|------|
| $W$ | 동결된 사전학습 가중치 |
| $B, A$ | 학습되는 저랭크 행렬 ($B=0$, $A\sim\mathcal N$로 초기화) |
| $r$ | rank. 학습 파라미터 $dk \to r(d+k)$ |
| $\alpha/r$ | 스케일링 계수 |

직관: 태스크 적응에 필요한 변화는 소수의 방향으로 충분하다는 가정 하에, 그 방향을 rank $r$ 부분공간으로 제한해 학습한다. 선형성 덕분에 추론 시 원본에 병합해 추가 비용 없이 쓴다.
