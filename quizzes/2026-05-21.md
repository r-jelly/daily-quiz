## Q1. SFT 손실함수와 Pre-training과의 차이

**Supervised Fine-Tuning(SFT)**는 사전학습된 언어 모델을 instruction-response 쌍 데이터로 미세조정하는 방법입니다.

**다음 세 가지를 설명하세요:**

1. **SFT의 손실함수** — SFT의 학습 목표(loss function)를 수식으로 쓰고, 사전학습(Pre-training)의 목표와 어떻게 다른지 설명하세요.

2. **SFT 데이터셋의 구성** — SFT 데이터셋은 일반적으로 어떤 형태(포맷)로 구성되며, 왜 모델의 "행동"을 바꾸는 데 효과적인가요?

### Answer 1.

1. SFT는 Pre-training과 동일하게 Cross-entropy 기반의 Next-token Prediction을 사용한다.

$$\mathcal{L}_{\text{SFT}} = -\sum_{t=1}^{T} \log P_\theta(y_t \mid x, y_{<t})$$

그러나 Pre-training은 모든 토큰에 대해서 loss를 계산하는 반면, SFT는 Instruction과 Input 부분은 제외하고 Output 부분에 대해서만 loss를 계산하는 학습 방식을 가진다. 즉, 프롬프트에 해당하는 토큰들을 마스킹해서 학습한다는 점이 다르다.

2. Instruction tuning을 위한 데이터셋은 일반적으로 (Instruction, Input)-Output의 형태를 띈다. 모델이 이미 언어능력을 갖추고 있는 상태에서, 특정 지시에 대한 답변을 통해 모델이 어떤 방식으로 응답해야 하는지를 학습하기 때문이다. 즉, 특별한 언어능력을 모델에 주입시키는 것이 아닌, 행동 패턴을 정렬(alignment)하는 것으로 볼 수 있다.

## Q2. Prompt Masking

SFT 학습 시, 입력 프롬프트(instruction)와 출력(response)이 함께 모델에 입력됩니다.

SFT에서 Instruction/Input 토큰의 손실을 마스킹하는 이유는 무엇일까요?

만약 마스킹하지 않고 모든 토큰에 대해 손실을 계산하면 어떤 문제가 생길 수 있는지 직관적으로 설명해 주세요. 아래 두 관점에서 생각해 보면 도움이 됩니다:

- 학습 목표의 관점: 우리가 원하는 게 뭔지
- 데이터 불균형의 관점: Instruction 길이 vs Output 길이

### Answer 2.

SFT는 Instruction/Input에 맞는 Output을 내도록 모델을 학습시키는 방법을 말한다. 이때, Instruction/Input 토큰까지 loss에 포함하게 된다면 모델이 Output 생성이 아닌, Instruction/Input 복원 능력을 더 많이 학습하게 된다.

즉, loss 값은 토큰 수에 비례하므로 Instruction/Input 토큰이 많을수록 해당 부분의 그래디언트 신호가 압도적이게 된다. 따라서 생성 능력보다 복원 능력을 더 많이 학습하게 되는 것이다.

## Q3. SFT의 한계와 RLHF의 필요성

SFT만으로 학습된 모델은 여러 한계를 가집니다.

**두 가지를 답하세요:**

1. **SFT의 한계** — SFT가 인간의 선호(human preference)를 완전히 반영하지 못하는 이유를 설명하세요.

2. **RLHF(Reinforcement Learning from Human Feedback)의 필요성** — SFT 이후 왜 RLHF 단계가 필요한지, 그리고 RLHF가 해결하려는 핵심 문제가 무엇인지 설명하세요.

### Answer 3.

1. SFT는 일종의 모방학습이다. Input-Output 쌍을 학습하므로 해당 데이터를 따라하도록 학습하게 되는데, 학습 데이터에 없는 새로운 질문이 들어오면 "특정 응답이 좋은지 나쁜지"를 판단할 수 없다. 

2. 사람은 완벽한 정답을 쓰기 어렵지만, A/B 중 어떤 응답이 더 나은 응답인지는 평가할 수 있다. 이러한 상대적인 선호도(reference)를 수집해서 reward model을 학습하고, 해당 모델을 통해 RL을 이용해 LLM을 학습하도록 한다. 이것이 RLHF이다.
