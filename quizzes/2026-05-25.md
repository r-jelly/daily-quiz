## Q1. RLHF-PPO의 한계와 DPO 수식 유도

**두 가지를 설명하세요:**

1. **RLHF-PPO의 한계** — RLHF-PPO 파이프라인의 실용적 문제점이 무엇인가요?

2. **DPO 수식 유도** — RLHF의 목표함수로부터 DPO 손실함수가 어떻게 유도되는지 설명하세요. 특히, Partition function $Z(x)$가 어떻게 소거되는지를 설명하세요.

$$\max_{\pi_\theta} \mathbb{E}_{x \sim \mathcal{D},\, y \sim \pi_\theta}\!\left[r(x,y)\right] - \beta \cdot \mathbb{KL}\!\left[\pi_\theta(y \mid x) \;\|\; \pi_{\text{ref}}(y \mid x)\right]$$

$$\Rightarrow \pi^*(y \mid x) = \frac{\pi_{\text{ref}}(y \mid x) \exp\!\left(\frac{1}{\beta} r(x,y)\right)}{Z(x)}$$

$$\mathcal{L}_{\text{DPO}} = -\mathbb{E}\!\left[\log \sigma\!\left(\beta \log \frac{\pi_\theta(y_w \mid x)}{\pi_{\text{ref}}(y_w \mid x)} - \beta \log \frac{\pi_\theta(y_l \mid x)}{\pi_{\text{ref}}(y_l \mid x)}\right)\right]$$

### Answer 1.

1. PPO 파이프라인의 문제점은 아래와 같다: 
- PPO 기반의 파이프라인은 Policy, Reference, Reward, Value model을 동시에 메모리에 올려서 사용해야 하므로 부담이 될 수 있다.
- 또한, Policy 모델이 실제 품질은 낮지만 Reward 점수만 높이는 방향으로 최적화될 수 있다. 이를 막기 위해서 KL penalty를 추가하기도 한다.

2. 기존 RLHF에서 최적 Policy $\pi^*$의 closed-form을 유도할 수 있다. 해당 식을 $r(x, y)$에 대해서 역으로 풀고 선호 데이터쌍 $(y_w, y_l)$에 대해서 reward의 차이를 구하면 최종 DPO 손실함수 형태가 된다.


## Q2. DPO의 β와 π_ref의 역할

**두 가지를 답하세요:**

1. **β(온도 파라미터)의 역할** — β가 크면/작으면 모델의 학습이 어떻게 달라지는지 설명하세요.

2. **π_ref(reference policy)의 역할** — Reference model이 없다면 어떤 문제가 생기는지, 그리고 실제로 어떤 모델을 π_ref로 사용하는지 설명하세요.

> 힌트: β → 0이면 어떤 극단적인 현상이 발생할까요?

### Answer 2.

1. $\beta$가 0에 가까워지면, 시그모이드 값이 상수가 되므로 학습이 거의 되지 않는다는 문제가 있다. 또한, 이는 KL 제약을 무시하는 것과 같으므로 reference model을 완전히 무시한다는 의미이기도 하다.

$\beta$가 무한대로 발산한다면, 시그모이드 값이 0 또는 1이 되므로 gradient vanishing 문제가 발생하게 된다.

2. Reference model은 AI가 원래의 언어 능력이나 다양성을 잃지 않도록 기준점 역할을 하는 고정된 모델이다. 따라서 reference model없이 학습하게 되면, 학습 데이터에 없는 능력(=문법, 상식 등)이 없어지거나(catastropic forgetting) 특정 패턴의 응답만 과도하게 생성(model collapse)하는 문제가 발생하게 된다.

## Q3. DPO의 한계와 보완 방법

DPO도 완벽하지 않습니다. **DPO의 주요 한계점 을 하나 이상 설명하고, 이를 보완하기 위해 제안된 방법(IPO, SimPO, GRPO 등 중 하나)의 핵심 아이디어를 간략히 설명**해 주세요.

> 힌트: DPO가 Bradley-Terry 모델을 암묵적으로 가정한다는 점, 그리고 offline 데이터에 의존한다는 점에서 어떤 문제가 생길 수 있을까요?

### Answer 3.

DPO는 고정된 선호 데이터셋으로만 학습하는 offline learning이다. 학습이 진행될수록 Policy model은 Reference model로부터 멀어지는데, 데이터는 reference model 기준으로 수집된 것이므로 학습 분포와 데이터 분포 사이의 괴리가 커진다. 즉, 현재 모델이 실제로는 생성하지 않을 응답들로 학습을 하게 된다.

GRPO는 이를 보완하기 위해서 제안된 방법 중 하나이다. 같은 질문에 대해서 $G$개의 응답을 생성하고, 그룹 내의 상대적 advantage를 baseline으로 사용하여 학습하게 된다. 따라서 GRPO는 별도의 Value function 없이도 Online learning이 가능하다는 장점이 있다.
