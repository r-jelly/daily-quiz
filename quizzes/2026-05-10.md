## Q1. Batch Normalization 수식과 Internal Covariate Shift

아래 두 가지를 설명하세요:

1. 정규화 후 왜 학습 가능한 파라미터 $\gamma$와 $\beta$를 추가하는지
2. Batch Normalization이 학습 과정에서 어떤 문제를 해결하기 위해 도입되었는지 (**Internal Covariate Shift** 개념 포함)

### Answer 1.

1. Batch Normalization의 수식은 아래와 같다:

$$
\hat{x}_i = \frac{x_i - \mu_\mathcal{B}}{\sqrt{\sigma^2_\mathcal{B} + \epsilon}}, \quad
y_i = \gamma \hat{x}_i + \beta
$$
여기서 $\mu_\mathcal{B}$와 $\sigma^2_\mathcal{B}$는 미니배치 내의 평균과 분산이다.
또한, BN의 출력은 $\hat x$가 아니라, 학습 가능한 파라미터 $\lambda$(스케일)와 $\beta$(이동)를 곱하고 더한값이다. 해당 파라미터가 없으면 모든 레이어의 출력이 평균 0, 분산 1로 고정되어 버리므로 모델이 표현할 수 있는 분포가 지나치게 제한된다. 즉, 모델 학습 과정에서 얼마나 정규화할지 학습하게 해주는 방식이다.

2. Internal Covariate Shift(ICS)는 앞 레이어의 파라미터가 업데이트 될 때마다 뒤 레이어가 받는 입력 분포가 계속 바뀌는 현상이다.

    Batch Normalization은 이 분포를 강제로 안정시켜서 더 높은 학습률을 사용할 수 있게 하고, 초기화에 덜 민감해지고, 학습 수렴 속도가 향상되는 이점을 주게 된다.

## Q2. 학습 vs 추론 시 BN 동작 차이

BN 수식에서 $\mu_B$와 $\sigma_B^2$는 **미니배치 통계**를 사용합니다.

**학습(train) 시와 추론(inference) 시에 BN의 동작 방식이 다릅니다. 어떻게 다른가요?**

추론 시에는 미니배치 통계 대신 무엇을 쓰며, 그 값은 어떻게 구하나요?

$$\mu_{\text{run}} \leftarrow \; ?$$

### Answer 2.

추론 시에는 미니배치 통계를 사용할 수 없다. 추론의 경우 배치 크기가 1인 경우가 많으므로 배치 통계를 사용하면 불안정하게 된다.

따라서 추론 시에는 학습 전체에 걸쳐 누적된 이동 평균을 사용하게 된다. 매 미니배치마다, 평균과 분산을 지수이동평균으로 누적해두고 추론 시에는 학습 때 구한 누적 이동 평균을 고정값으로 사용한다.

$$
\mu_{\text{run}} \leftarrow (1-\alpha)\mu_{\text{run}} + \alpha\mu_B
$$
$$
\sigma_\text{run}^2 \leftarrow (1-\alpha)\sigma_{\text{run}}^2 + \alpha\sigma_B^2
$$

즉, 학습 내내 본 모든 배치의 누적 통계를 사용한다. 따라서 추론 시에 배치 크기와 무관하게 안정적으로 정규화가 가능하다.

## Q3. Batch Normalization vs Layer Normalization 비교

**배치 정규화(BN)와 레이어 정규화(Layer Normalization)의 차이는 무엇인가요?**

Transformer 계열 모델(GPT, BERT 등)에서는 왜 BN 대신 **LayerNorm**을 주로 사용하는지 이유도 함께 설명하세요.

아래 두 방식이 통계를 계산하는 **축(axis)**의 차이를 중심으로 답하세요:

$$\text{BN: } \mu_j = \frac{1}{m}\sum_{i=1}^{m} x_{ij} \qquad \text{vs} \qquad \text{LN: } \mu_i = \frac{1}{d}\sum_{j=1}^{d} x_{ij}$$

### Answer 3.

Batch Normalization은 입력된 미니배치 내 모든 데이터의 같은 feature 위치의 값들을 모아서 평균, 분산을 계산하지만, Layer Normalization은 한 개의 샘플 내 모든 feature 값으로 평균, 분산을 계산한다.

Transformer 계열 모델에서 Layer Noramlization을 주로 사용하는 이유는 크게 세 가지를 들 수 있다.
1. Input sequence 길이가 다를 때 Batch Normalization은 통계 편향이 발생할 수 있다.
2. 배치 크기가 작거나 1인 경우, Batch Normalization은 통계 추정이 불안정해지는 반면, Layer Normalization은 배치 크기와 완전히 무관하게 동작한다.
3. Batch Normalization은 추론 시를 위해, 학습 시점에서의 통계를 별도로 관리해야 하는 문제점이 있는데, Layer Normalization은 추론과 학습 모두 동일한 방식으로 동작하므로 훨씬 더 간단하다.
