## Q1. 드롭아웃(Dropout) 동작 방식

드롭아웃은 신경망의 과적합(overfitting)을 방지하는 대표적인 정규화 기법입니다.

**두 가지를 설명하세요:**

1. 드롭아웃의 동작 방식을 **학습(training) 시**와 **추론(inference) 시**로 나누어 설명하고, 추론 시 왜 별도의 처리가 필요한지 수식과 함께 설명하세요.

2. 드롭아웃이 과적합을 줄이는 이유를 **앙상블(ensemble) 관점**에서 직관적으로 설명하세요.

> 힌트: 드롭아웃 비율을 $p$라 할 때, 학습과 추론에서 각 뉴런의 출력값이 어떻게 달라지는지 $\mathbb{E}[\cdot]$를 이용해 표현해보세요.

### Answer 1.

1. 드롭 확률을 $p$로 정의했을 때,
    - 학습 시 $1-p$ 확률로 각 뉴런이 활성화된다. 즉, 각 뉴런의 기댓값은 $\mathbb{E}[z]=(1-p)\cdot x$이다.
    - 추론 시에는 모든 뉴런의 값에 $(1-p)$를 곱해주게 된다.
    - 또는 Inverted Dropout과 같이, 학습 시 살아남은 뉴런에 $\frac{1}{1-p}$를 곱하고, 추론 시에 아무 처리도 하지 않는 방법을 이용할 수 있다.

2. 앙상블은 서로 다른 여러 모델의 결과를 결합해서 모델의 과적합을 막고 일반화 성능을 높이고자 하는 방법론이다. Dropout을 이용한 학습은 이와 같이 수 많은 sub-network를 구성하면서 학습하는 것과 같기 때문에 단일 모델 상에서 앙상블과 유사한 효과를 얻을 수 있다.


## Q2. Inverted Dropout과 기댓값 증명

**Inverted Dropout**은 현재 PyTorch 등 대부분의 딥러닝 프레임워크에서 사용하는 방식입니다.

드롭 확률을 $p$라 할 때, Inverted Dropout의 학습 시 연산을 수식으로 표현하고, **왜 추론 시에는 별도의 스케일링이 불필요한지** 기댓값 $\mathbb{E}[\cdot]$를 이용해 증명하세요.

$$\mathbb{E}[z_{\text{inv}}] = \; ?$$

### Answer 2.

일반적인 Dropout에서 학습 시 각 뉴런의 기댓값은 아래와 같다:
$$
\mathbb{E}[z] = (1-p) \cdot x
$$
이때, 뉴런에 $\frac{1}{(1-p)}$를 곱해주게 되면, 뉴런의 기댓값은:
$$
\mathbb{E}[z_{inv}] = (1-p)\cdot x\cdot \frac{1}{1-p} = x
$$
따라서 학습과 추론의 기댓값이 동일하게 맞취지므로 추론 시 추가적인 스케일링이 불필요하다.

## Q3. Dropout + Batch Normalization 함께 사용 시 문제

실무에서 Dropout과 **Batch Normalization(BN)**을 함께 사용하면 문제가 생길 수 있다는 것이 알려져 있습니다.

**두 가지를 답하세요:**

1. Batch Normalization이 학습 시 수행하는 연산을 수식으로 쓰세요. (평균 $\mu_\mathcal{B}$, 분산 $\sigma^2_\mathcal{B}$, 학습 파라미터 $\gamma, \beta$ 포함)

$$\hat{x}_i = \; ?, \qquad y_i = \; ?$$

2. Dropout을 BN **앞**에 적용했을 때 어떤 문제가 발생하는지, **"variance shift"** 라는 키워드를 사용해 설명하세요.

### Answer 3.

1. Batch Normalization의 수식은 아래와 같다:
$$
\hat x_i = \frac{x_i-\mu_B}{\sqrt{\sigma^2_B+\epsilon}}, \quad y_i = \gamma\hat x_i + \beta
$$
즉, mini-batch내 모든 데이터 각각의 feature 간의 평균과 분산을 이용해 정규화를 진행하게 된다.

2. Dropout을 Batch Normalization 앞에 적용하게 된다면, 학습 시에 Dropout으로 인해서 Batch Normalization에 이용되는 입력의 분산이 작고 (많은 값이 0이 되므로), 해당 분포를 기준으로 정규화가 진행된다.

    그러나, 추론 시에는 Dropout이 없어 입력 분산이 커지게 되므로, Batch Normalization이 학습에서 쌓은 통계와 실제 분포가 어긋나게 된다. 이를 Variance shift라고 한다.
